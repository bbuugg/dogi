Why Dogi

工作台 =
主机 + 工具 + Agent

模型负责推理，剩下的事情由工作台负责：接进来、看得见、动得了、说得清。下面三件事就是 Dogi 的全部野心。

01 / 主机接入

每台机器都一样接进来

本地终端、SSH、Mosh、远程桌面 RDP 统一成「主机」一种对象；平台探测、终端编码、凭据加密都在接入时处理掉，不留给使用者。

02 / 工具齐备

干活的东西都在手边

SFTP 文件管理、服务器监控、接口调试、笔记、脚本、插件 —— 不是拼链接，而是同一个窗口、同一套多标签与分屏。

03 / Agent 驱动

AI 直接落在真实环境上

工具调用落到真实终端与真实文件：命令实时输出、权限确认、超长输出落产物，全在同一个会话里看得见。

Hosts

连机器这件事，管到底

远程桌面、文件传输、监控、中文乱码、Windows 主机 —— 这些坑基本都踩过，并且在代码里处理掉了。

一个窗口把所有事情做完

  • 本地终端：node-pty，自动探测 PowerShell / pwsh / CMD / Git Bash / WSL / bash / zsh / fish。
  • SSH：密码或私钥，握手进度实时推送，失败自动重连，keepalive，多会话并存。
  • Mosh：UDP 直连，SSH 只做引导，适合高延迟链路。
  • 远程桌面：内嵌 WASM 客户端，不调 mstsc；支持缩放、键盘鼠标、Ctrl+Alt+Del。
  • 多标签 + 分屏：上下左右拆分、拖拽调比例、标签跨组移动，换父节点后回放缓冲画面不丢。
  • SFTP：上传下载（含目录递归）、远端复制移动，多任务并发进度统一进状态栏托盘。
  • zmodem：终端里 sz / rz 直接传文件；拖拽到终端走 SFTP。
  • 服务器监控：CPU / 内存 / 负载 / 网速 / 磁盘；非 Linux 主机显式显示不支持，而不是静默消失。
  • 中文乱码：每主机可选 UTF-8 / GBK，只在 SSH 边界转码，下游恒为 UTF-8。
  • 凭据：密码 / 私钥用 safeStorage 加密，列表接口只回 hasPassword 这类脱敏标记。
The agent

Agent 知道
自己在哪台机器上

它不是只会聊天。下面是一次真实形态的会话：模型探到根分区快满了，顺手查了日志目录，然后停下来问你要不要继续。

工具调用落在真实环境上

  • 两条产品线：终端内嵌助手（绑定当前会话）+ 工作区 Agent（绑定本地目录），共享同一套流式事件。
  • 模型自选：OpenAI / Anthropic / DeepSeek / Google / 任意 OpenAI 兼容接口（Ollama、vLLM、中转网关）。
  • 模型按会话独立：同一个应用里可以一边跑推理模型、一边跑本地模型。
  • 权限两档：直接执行 / 执行前弹确认卡，输入框处实时切换；单条命令还能中途叫停。
  • 技能系统：按 Agent Skills 约定自建，提示词只放名称与描述，正文按需读取。
  • MCP：接入任意 stdio MCP server，工具自动合并；可挂允许清单。
  • 可换后端：内置 ai-sdk，或连外部 ACP agent（Dogi 作为 ACP 客户端，消息在外部agent 手上）。
  • 超长输出落产物：写命令订阅实时流，超限只给 id，让模型自己续读。

Tools

笔记、脚本、插件

  • HTTP：请求头保留空行、四种请求体形态、超时、代理、跳过 TLS 校验、手动取消。
  • cURL 导入：粘一段 curl 直接变成可执行的请求。
  • WebSocket：握手头、子协议、wss 自签证书、文本 / 二进制帧。
  • 历史：留存请求历史，显示响应耗时与体积。
插件
  • 形态：一个目录 + plugin.json（主进程 main.js + 渲染端 renderer.js）。
  • 加载：宿主读源码 → blob import → activate(api) 注册视图。
  • 注入：api.antd / api.icons / api.MonacoEditor / api.cn / api.react，插件不自带依赖。
  • 权限：storage / http 在 manifest 里声明，主进程侧可 registerHandler 暴露自有通道。
  • 命令：插件可注册命令，出现在命令面板（Ctrl+Shift+P）里。
内置：Redis 客户端内置：端口占用可自行扩展
Security

边界画在
代码里

  • 凭据用 safeStorage 加密（Windows 走 DPAPI），只在主进程解密。
  • 渲染进程 contextIsolation + preload 白名单 IPC，严格 CSP。
  • Agent 的文件操作都过 resolveInside 做工作区越界检查。
  • 媒体预览走受限的自定义协议 dogi-ws://，不把文件塞进 DOM。
  • 数据导出打包成 zip 时不含凭据。

Develop

从源码跑起来

Electron 44 + React 19 + TypeScript 7 + Vite 8。没有 electron-vite —— 三个 Vite 配置各自独立，dev 编排在 scripts/dev.mjs。

$ git clone https://github.com/bbuugg/dogi.git
$ cd dogi && npm install
# npm 12 的 install-scripts 策略：若提示脚本被阻止
$ npm install-scripts approve electron esbuild node-pty ssh2
$ npm run dev
   Vite dev server + main/preload watch + Electron 自动重启
  • npm run build：类型检查 + main / preload / renderer 全量构建到 out/。
  • npm run typecheck：node 侧与 web 侧两套 tsconfig 都过。
  • npm run dist:win：打包（另有 dist / dist:mac / dist:linux）。
  • npm run check:docs：扫文档里的文件与包名引用，逐个对磁盘核一遍。
  • AGENTS.md：架构约定、关键机制与全部实测踩坑都在那里，改动前先读。
